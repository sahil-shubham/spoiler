# Security policy

Report security vulnerabilities privately using [GitHub's security advisory form](https://github.com/sahil-shubham/spoiler/security/advisories/new). Do not include secrets or private recordings in a public issue. Include a minimal synthetic reproducer if possible.

Recordings and vocabulary sources are untrusted input. Treat recordings as sensitive: review what you send to PostHog or OpenRouter, avoid committing real sessions, and keep credentials out of command-line arguments and logs. Do not rely on an analysis as a security decision.
